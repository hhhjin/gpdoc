Italic adds the `italic` mark. Use it for emphasis, book titles, or terms from another language.

## Try it

<PluginExample plugin="italic" />

## Install

From your [Quickstart project](/docs/quickstart/), add the plugin.

```sh
cargo add gpdoc-plugin-italic
```

Register `gpdoc_plugin_italic::italic()` alongside `paragraph()`.

## Example

The first paragraph starts at document position `1`. The range `14..33` selects `Pride and Prejudice`. Put the example in the Quickstart project's `src/main.rs`. Run `cargo run` to print the edited paragraph as JSON.

```rust
use gpdoc::{DocPos, Editor, EditorConfig, Error, Node, Selection};
use gpdoc_plugin_italic::italic;
use gpdoc_plugin_paragraph::paragraph;

fn main() -> Result<(), Error> {
	let config = EditorConfig::builder()
	    .plugin(paragraph())
	    .plugin(italic())
	    .build()?;
	let mut editor = Editor::from_document(&config, vec![Node::text("paragraph", "A title like Pride and Prejudice takes italics.")])?;
	editor.select(Selection::Text {
		anchor: DocPos(14),
		head: DocPos(33),
	})?;

	editor.run(gpdoc_plugin_italic::Toggle)?;
	println!("{}", editor.document().blocks()[0].to_json());
	Ok(())
}
```

Only the title appears in italics.

## Commands

These commands take no arguments. Select text to change its formatting, or place the caret where you want to start typing. `editor.run` returns `Result<CommandOutcome, Error>`. A handled command returns `Applied(AppliedChange)`. Set and toggle return `NotApplicable` if no text can take the mark.

### `setItalic`

Apply italic to the selection or to the next characters typed at the caret.

```rust
editor.run(gpdoc_plugin_italic::Set)?;
```

### `toggleItalic`

Switch italic off when the whole eligible selection has the mark. On a mixed selection, apply it throughout.

```rust
editor.run(gpdoc_plugin_italic::Toggle)?;
```

### `unsetItalic`

Clear italic from the selection or turn it off for subsequent typing.

```rust
editor.run(gpdoc_plugin_italic::Unset)?;
```

## Keyboard shortcuts

Toggle italic with **Command + I** on macOS or **Ctrl + I** on Windows and Linux.

Typing `*emphasis*` or `_emphasis_` applies italic.

## Native appearance

Enable the `gpui` feature on `gpdoc-plugin-italic`. In a GPUI editor, `italic()` uses italics. To supply your own formatter, import `gpdoc::PluginViewExt` and register `italic().with_view(my_italic_view)`.
