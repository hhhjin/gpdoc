Highlight adds the `highlight` mark. Use it to call attention to a phrase while keeping the text color intact.

## Try it

<PluginExample plugin="highlight" />

## Install

From your [Quickstart project](/docs/quickstart/), add the plugin.

```sh
cargo add gpdoc-plugin-highlight
```

Add `gpdoc_plugin_highlight::highlight()` to your editor config to store highlights on text.

## Example

The first paragraph starts at document position `1`. The range `12..20` selects `notebook`. Put the example in the Quickstart project's `src/main.rs`. Run `cargo run` to print the edited paragraph as JSON.

```rust
use gpdoc::{DocPos, Editor, EditorConfig, Error, Node, Selection};
use gpdoc_plugin_highlight::highlight;
use gpdoc_plugin_paragraph::paragraph;

fn main() -> Result<(), Error> {
	let config = EditorConfig::builder()
	    .plugin(paragraph())
	    .plugin(highlight())
	    .build()?;
	let mut editor = Editor::from_document(&config, vec![Node::text("paragraph", "Bring your notebook to the workshop.")])?;
	editor.select(Selection::Text {
		anchor: DocPos(12),
		head: DocPos(20),
	})?;

	editor.run(gpdoc_plugin_highlight::Set(None))?;
	println!("{}", editor.document().blocks()[0].to_json());
	Ok(())
}
```

The word `notebook` now carries the highlight mark.

## Settings

### `highlight`

Use this constructor for highlights with a shared appearance. Choose a fallback RGB color in the GPUI formatter to give these marks a visible background.

```rust
use gpdoc::EditorConfig;
let config = EditorConfig::builder()
    .plugin(paragraph())
    .plugin(highlight())
    .build()?;
```

### `multicolor_highlight`

Use this constructor for a color picker. Each mark gains a nullable `color` string, initially `null`. Marks with an empty or invalid color inherit their background unless the app supplies a fallback.

```rust
use gpdoc::EditorConfig;
use gpdoc_plugin_highlight::multicolor_highlight;

let config = EditorConfig::builder()
    .plugin(paragraph())
    .plugin(multicolor_highlight())
    .build()?;
```

## Commands

At a caret, highlight commands change the formatting for subsequent typing. `editor.run` returns `Result<CommandOutcome, Error>`. Set and toggle return `NotApplicable` when the selection cannot take a highlight.

### `setHighlight`

Apply a highlight, or update the color of an existing one. With multicolor enabled, pass a CSS color string as shown. For the configured default on unmarked text, pass `None`.

```rust
editor.run(gpdoc_plugin_highlight::Set(Some("#ffa8a8".into())))?;
```

### `toggleHighlight`

Toggle the highlight regardless of color. In multicolor mode you can pass the same `color` argument as `setHighlight`. The command removes the highlight if the whole eligible selection matches that color and otherwise applies it.

```rust
editor.run(gpdoc_plugin_highlight::Toggle(None))?;
```

### `unsetHighlight`

Remove the highlight regardless of its color.

```rust
editor.run(gpdoc_plugin_highlight::Unset)?;
```

## Keyboard shortcuts

Toggle highlighting with **Command + Shift + H** on macOS or **Ctrl + Shift + H** on Windows and Linux.

Typing `==important==` highlights the word between the delimiters.

## Native appearance

Enable the `gpui` feature on `gpdoc-plugin-highlight`. In a GPUI editor, `multicolor_highlight()` uses the CSS color stored on each mark. An uncolored mark inherits its background. To choose a fallback for marks with a missing or invalid color, import `gpdoc::PluginViewExt` and register `highlight().with_view(|| highlight_format([255, 232, 135]))` or attach the same view to `multicolor_highlight()`.
