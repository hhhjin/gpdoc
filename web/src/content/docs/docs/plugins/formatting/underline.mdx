Underline adds the `underline` mark. It can mark a label in a worksheet or a term to review.

## Try it

## Install

From your [Quickstart project](/docs/quickstart/), add the plugin.

```sh
cargo add gpdoc-plugin-underline
```

Register `gpdoc_plugin_underline::underline()` alongside `paragraph()`.

## Example

The first paragraph starts at document position `1`. The range `1..5` selects `Sign`. Put the example in the Quickstart project's `src/main.rs`. Run `cargo run` to print the edited paragraph as JSON.

```rust
use gpdoc::{DocPos, Editor, EditorConfig, Error, Node, Selection};
use gpdoc_plugin_underline::underline;
use gpdoc_plugin_paragraph::paragraph;

fn main() -> Result<(), Error> {
	let config = EditorConfig::builder()
	    .plugin(paragraph())
	    .plugin(underline())
	    .build()?;
	let mut editor = Editor::from_document(&config, vec![Node::text("paragraph", "Sign and date this form.")])?;
	editor.select(Selection::Text {
		anchor: DocPos(1),
		head: DocPos(5),
	})?;

	editor.run(gpdoc_plugin_underline::Toggle)?;
	println!("{}", editor.document().blocks()[0].to_json());
	Ok(())
}
```

The line runs under `Sign`. The underline mark carries no link destination.

## Commands

These commands take no arguments. Select text to change its formatting, or place the caret where you want to start typing. `editor.run` returns `Result<CommandOutcome, Error>`. A handled command returns `Applied(AppliedChange)`. Set and toggle return `NotApplicable` if no text can take the mark.

### `setUnderline`

Apply underline to the selection or to the next characters typed at the caret.

```rust
editor.run(gpdoc_plugin_underline::Set)?;
```

### `toggleUnderline`

Switch underline off when the whole eligible selection has the mark. On a mixed selection, apply it throughout.

```rust
editor.run(gpdoc_plugin_underline::Toggle)?;
```

### `unsetUnderline`

Clear underline from the selection or turn it off for subsequent typing.

```rust
editor.run(gpdoc_plugin_underline::Unset)?;
```

## Keyboard shortcuts

Toggle underline with **Command + U** on macOS or **Ctrl + U** on Windows and Linux.

## Native appearance

In a GPUI editor, `underline()` underlines marked text. To supply your own formatter, import `gpdoc::PluginViewExt` and register `underline().with_view(my_underline_view)`.
