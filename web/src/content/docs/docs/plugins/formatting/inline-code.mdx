Inline code adds the `code` mark. Use it for a function name, a command such as `cargo build`, or a short code fragment within a sentence.

## Try it

## Install

From your [Quickstart project](/docs/quickstart/), add the plugin.

```sh
cargo add gpdoc-plugin-inline-code
```

Register `gpdoc_plugin_inline_code::inline_code()` alongside `paragraph()`.

## Example

The first paragraph starts at document position `1`. The range `5..16` selects `cargo build`. Put the example in the Quickstart project's `src/main.rs`. Run `cargo run` to print the edited paragraph as JSON.

```rust
use gpdoc::{DocPos, Editor, EditorConfig, Error, Node, Selection};
use gpdoc_plugin_inline_code::inline_code;
use gpdoc_plugin_paragraph::paragraph;

fn main() -> Result<(), Error> {
	let config = EditorConfig::builder()
	    .plugin(paragraph())
	    .plugin(inline_code())
	    .build()?;
	let mut editor = Editor::from_document(&config, vec![Node::text("paragraph", "Run cargo build before publishing.")])?;
	editor.select(Selection::Text {
		anchor: DocPos(5),
		head: DocPos(16),
	})?;

	editor.run(gpdoc_plugin_inline_code::Set)?;
	println!("{}", editor.document().blocks()[0].to_json());
	Ok(())
}
```

The command uses a monospace font and stays in the same paragraph as the surrounding words.

## Commands

These commands take no arguments. Select text to change its formatting, or place the caret where you want to start typing. `editor.run` returns `Result<CommandOutcome, Error>`. A handled command returns `Applied(AppliedChange)`. Set and toggle return `NotApplicable` if no text can take the mark.

### `setCode`

Apply inline code to the selection or to the next characters typed at the caret.

```rust
editor.run(gpdoc_plugin_inline_code::Set)?;
```

### `toggleCode`

Switch inline code off when the whole eligible selection has the mark. On a mixed selection, apply it throughout.

```rust
editor.run(gpdoc_plugin_inline_code::Toggle)?;
```

### `unsetCode`

Clear inline code from the selection or turn it off for subsequent typing.

```rust
editor.run(gpdoc_plugin_inline_code::Unset)?;
```

## Keyboard shortcuts

Toggle inline code with **Command + E** on macOS or **Ctrl + E** on Windows and Linux.

Wrap a phrase in single backticks to apply inline code as you type. The `code` mark excludes other marks on the same text.

## Native appearance

Enable the `gpui` feature on `gpdoc-plugin-inline-code`. In a GPUI editor, `inline_code()` sets marked text in monospace. To supply your own formatter, import `gpdoc::PluginViewExt` and register `inline_code().with_view(my_inline_code_view)`.
