Text style adds the `textStyle` mark. It can store multiple style properties on the same text, such as a custom color and font size.

## Try it

<PluginExample plugin="text-style" />

## Install

From your [Quickstart project](/docs/quickstart/), add the plugin.

```sh
cargo add gpdoc-plugin-text-style
```

Add `gpdoc_plugin_text_style::text_style_kit()` to your editor config to install the mark and all five style properties.

## Example

The first paragraph starts at document position `1`. The range `1..14` selects `Release notes`. Put the example in the Quickstart project's `src/main.rs`. Run `cargo run` to print the edited paragraph as JSON.

```rust
use gpdoc::{DocPos, Editor, EditorConfig, Error, Node, Selection};
use gpdoc_plugin_text_style::text_style_kit;
use gpdoc_plugin_paragraph::paragraph;

fn main() -> Result<(), Error> {
	let config = EditorConfig::builder()
	    .plugin(paragraph())
        .plugins(text_style_kit())
	    .build()?;
	let mut editor = Editor::from_document(&config, vec![Node::text("paragraph", "Release notes")])?;
	editor.select(Selection::Text {
		anchor: DocPos(1),
		head: DocPos(14),
	})?;

	editor.run(gpdoc_plugin_text_style::SetColor(Some("#2456aa".into())))?;
	editor.run(gpdoc_plugin_text_style::SetFontSize(Some("18px".into())))?;
	println!("{}", editor.document().blocks()[0].to_json());
	Ok(())
}
```

To restore the default size while keeping the blue color, run `unsetFontSize` on the same selection.

## Settings

### `text_style_kit`

Install the mark and all five properties with `text_style_kit()`. For a smaller config, register `text_style()` with one or more of `color()`, `background_color()`, `font_family()`, `font_size()`, and `line_height()`.

```rust
use gpdoc::EditorConfig;
use gpdoc_plugin_text_style::{color, text_style};

let config = EditorConfig::builder()
    .plugin(paragraph())
    .plugin(text_style())
    .plugin(color())
    .build()?;
```

### `StyleProperty::on`

Choose which registered node or mark types accept an attribute. `on(self, types: impl IntoIterator<Item = impl Into<String>>)` accepts the variants `Color`, `BackgroundColor`, `FontFamily`, `FontSize`, and `LineHeight`. Include `textStyle` to use that property with the text commands below.

```rust
use gpdoc::EditorConfig;
use gpdoc_plugin_text_style::{text_style, StyleProperty};

let color = StyleProperty::Color.on(["textStyle", "paragraph"]);
let config = EditorConfig::builder()
    .plugin(paragraph())
    .plugin(text_style())
    .plugin(color)
    .build()?;
```

## Commands

Each setter accepts `Some(value)` to assign a string or `None` to clear it. A setter preserves the other properties. An unset command clears its property and runs `removeEmptyTextStyle`. `editor.run` returns `Result<CommandOutcome, Error>`. A setter returns `NotApplicable` when the selection cannot take the style.

### `setColor`

Set the foreground color of the selected text.

```rust
editor.run(gpdoc_plugin_text_style::SetColor(Some("#2456aa".into())))?;
```

### `unsetColor`

Clear its foreground color.

```rust
editor.run(gpdoc_plugin_text_style::UnsetColor)?;
```

### `setBackgroundColor`

Set the background behind selected characters.

```rust
editor.run(gpdoc_plugin_text_style::SetBackgroundColor(Some("#ffe887".into())))?;
```

### `unsetBackgroundColor`

Clear the background color from selected characters.

```rust
editor.run(gpdoc_plugin_text_style::UnsetBackgroundColor)?;
```

### `setFontFamily`

Set the font family. Supply a CSS family name or a comma-separated list.

```rust
editor.run(gpdoc_plugin_text_style::SetFontFamily(Some("Georgia, serif".into())))?;
```

### `unsetFontFamily`

Restore the inherited font family.

```rust
editor.run(gpdoc_plugin_text_style::UnsetFontFamily)?;
```

### `setFontSize`

Set the font size using a CSS length. GPUI renders common lengths such as `px`, `em`, and `rem`. Your host must resolve expressions such as `calc()` and `var()`.

```rust
editor.run(gpdoc_plugin_text_style::SetFontSize(Some("18px".into())))?;
```

### `unsetFontSize`

Restore the inherited font size.

```rust
editor.run(gpdoc_plugin_text_style::UnsetFontSize)?;
```

### `setLineHeight`

Set line height using a CSS value. A unitless number specifies a multiple of the font size.

```rust
editor.run(gpdoc_plugin_text_style::SetLineHeight(Some("1.5".into())))?;
```

### `unsetLineHeight`

Restore the inherited line height.

```rust
editor.run(gpdoc_plugin_text_style::UnsetLineHeight)?;
```

### `toggleTextStyle`

Set the style fields to match. If all eligible text already matches, remove the whole mark. Otherwise merge the supplied values with existing styles.

```rust
editor.run(gpdoc_plugin_text_style::Toggle {
    font_size: Some("18px".into()),
    ..Default::default()
})?;
```

### `removeEmptyTextStyle`

Remove marks in the selection when all their properties are null or empty strings.

```rust
editor.run(gpdoc_plugin_text_style::RemoveEmpty)?;
```

## Native appearance

In a GPUI editor, `text_style()` renders the color, font and line-height attributes installed on the mark. The property plugins also render their own attribute on additional node or mark types passed to `StyleProperty::on`. To replace the mark’s appearance, import `gpdoc::PluginViewExt` and register `text_style().with_view(my_text_style_view)`. Override a custom target’s formatter on its property plugin.
