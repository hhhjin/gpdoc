Strikethrough adds the `strike` mark. Use it to show a replaced price or a step the reader has completed.

## Try it

<PluginExample plugin="strike" />

## Install

From your [Quickstart project](/docs/quickstart/), add the plugin.

```sh
cargo add gpdoc-plugin-strike
```

Register `gpdoc_plugin_strike::strike()` alongside `paragraph()`.

## Example

The first paragraph starts at document position `1`. The range `12..15` selects `$49`. Put the example in the Quickstart project's `src/main.rs`. Run `cargo run` to print the edited paragraph as JSON.

```rust
use gpdoc::{DocPos, Editor, EditorConfig, Error, Node, Selection};
use gpdoc_plugin_strike::strike;
use gpdoc_plugin_paragraph::paragraph;

fn main() -> Result<(), Error> {
	let config = EditorConfig::builder()
	    .plugin(paragraph())
	    .plugin(strike())
	    .build()?;
	let mut editor = Editor::from_document(&config, vec![Node::text("paragraph", "Old price: $49. New price: $29.")])?;
	editor.select(Selection::Text {
		anchor: DocPos(12),
		head: DocPos(15),
	})?;

	editor.run(gpdoc_plugin_strike::Toggle)?;
	println!("{}", editor.document().blocks()[0].to_json());
	Ok(())
}
```

The old price appears crossed out. The new price still appears at normal weight with no line through it.

## Commands

These commands take no arguments. Select text to change its formatting, or place the caret where you want to start typing. `editor.run` returns `Result<CommandOutcome, Error>`. A handled command returns `Applied(AppliedChange)`. Set and toggle return `NotApplicable` if no text can take the mark.

### `setStrike`

Apply strikethrough to the selection or to the next characters typed at the caret.

```rust
editor.run(gpdoc_plugin_strike::Set)?;
```

### `toggleStrike`

Switch strikethrough off when the whole eligible selection has the mark. On a mixed selection, apply it throughout.

```rust
editor.run(gpdoc_plugin_strike::Toggle)?;
```

### `unsetStrike`

Clear strikethrough from the selection or turn it off for subsequent typing.

```rust
editor.run(gpdoc_plugin_strike::Unset)?;
```

## Keyboard shortcuts

Toggle strikethrough with **Command + Shift + S** on macOS or **Ctrl + Shift + S** on Windows and Linux.

Typing `~~old price~~` applies strikethrough.

## Native appearance

Enable the `gpui` feature on `gpdoc-plugin-strike`. In a GPUI editor, `strike()` draws a line through marked text. To supply your own formatter, import `gpdoc::PluginViewExt` and register `strike().with_view(my_strike_view)`.
