## Register the plugin

Add the crate to your [Quickstart app](/docs/quickstart/#configure-the-editor).

```sh
cargo add gpdoc-plugin-drag-handle
```

```rust
use gpdoc_plugin_drag_handle::drag_handle;
use gpdoc_plugin_paragraph::paragraph;

let config = gpdoc::EditorConfig::builder()
    .plugin(paragraph())
    .plugin(drag_handle())
    .build()?;
```

To customize the handle and drag preview, pass a renderer to `drag_handle().with_view(...)`.
