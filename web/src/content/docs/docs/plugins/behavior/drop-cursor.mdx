## Register the plugin

In the [Quickstart app](/docs/quickstart/#configure-the-editor), add the crate and register the plugin.

```sh
cargo add gpdoc-plugin-drop-cursor
```

```rust
use gpdoc_plugin_drop_cursor::drop_cursor;
use gpdoc_plugin_paragraph::paragraph;

let config = gpdoc::EditorConfig::builder()
    .plugin(paragraph())
    .plugin(drop_cursor())
    .build()?;
```

The painter receives the measured insertion bounds, window, and app. For a custom color, pass `|bounds, window, _| window.paint_quad(gpui::fill(bounds, gpui::rgb(0x4263eb)))` to `.with_view(...)`.

Drag a file over the editor to see the colored indicator follow a valid drop position. To import files at that position, register the [File handler](/docs/plugins/behavior/file-handler/) with your app's import callback.
