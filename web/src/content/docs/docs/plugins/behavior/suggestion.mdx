`Trigger` finds text after a character such as `@` at the caret. Use the query to filter a mention picker in your app.

## Install

Run this from a [Quickstart project](/docs/quickstart/).

```sh
cargo add gpdoc-plugin-suggestion
```

## Show a picker in GPUI

The [mention picker](/docs/plugins/media/mention/#compose-the-picker-and-inserted-chip) and [slash picker](/docs/plugins/behavior/slash-command/#register-your-commands) share the suggestion list, keyboard navigation, and click handling. Each editor keeps its own active item and dismissed query.

For another trigger, use `suggestion_picker(name, matcher, items, render)` inside your plugin's view function. The matcher returns a `SuggestionMatch` for the active query. For each candidate, return a `SuggestionItem::new(value, command)`. For a plain picker, return `menu.labeled_list(|value| value.name.clone())` when your record has a `name: String` field. For a custom layout, the render function receives the typed values through `menu.list(...)` and anchors its content with `menu.popover(...)`. Attach the view with `.plugin(my_plugin().with_view(my_menu))` after importing `gpdoc::PluginViewExt`.

## Read a mention query at the caret

The suggestion crate supplies a helper that works with an existing editor. A config containing just `paragraph()` is enough to look up a query.

With the paragraph plugin installed, put the caret at the end of `Ask @Ada`. The query excludes the trigger character.

```rust
use gpdoc::{DocPos, Editor, EditorConfig, Node, Selection};
use gpdoc_plugin_paragraph::paragraph;
use gpdoc_plugin_suggestion::Trigger;

let config = EditorConfig::builder()
    .plugin(paragraph())
    .build()?;
let editor = Editor::from_document(&config, vec![Node::text("paragraph", "Ask @Ada")])?;
let result = Trigger::new('@')
	.find(editor.document(), Selection::caret(DocPos(9)))
	.expect("mention query at the caret");

assert_eq!(result.query, "Ada");
assert_eq!(result.range, DocPos(5)..DocPos(9));
```

## Trigger settings

### Trigger character

Construct a `Trigger` with the character that opens your picker. The public `character: char` field holds it.

```rust
let trigger = Trigger::new('@');
```

### Allowed prefixes

By default, a trigger can appear at the start of the examined text or immediately after a space. This keeps the picker closed in `ada@example.org`. Set `allowed_prefixes: Option<Vec<char>>` to `None` to permit any prefix.

```rust
let mut trigger = Trigger::new('@');
trigger.allowed_prefixes = Some(vec![' ', '(']);
```

### Spaces in queries

Set `allow_spaces` to match a full name such as `@Ada Lovelace`. The default is `false`.

```rust
let mut trigger = Trigger::new('@');
trigger.allow_spaces = true;
```

### Repeated trigger characters

Set `allow_to_include_char` to keep another trigger inside the query. This option defaults to `false` and takes precedence over `allow_spaces`.

```rust
let mut trigger = Trigger::new(':');
trigger.allow_to_include_char = true;
```

### Start of line

Set `start_of_line` to require the trigger at the beginning of the line examined by the matcher. The default is `false`.

```rust
let mut trigger = Trigger::new('/');
trigger.start_of_line = true;
```

## Handle a suggestion

### find

Pass a document and a collapsed text selection. The return value is `Option<SuggestionMatch>`. Use `query: String` to filter choices, `text: String` for the full typed token, and `range: Range<DocPos>` for its location.

```rust
let matched = Trigger::new('@').find(editor.document(), editor.selection());
```

### replace_with_atom

Inside a command handler, supply the selected choice as a registered inline leaf node allowed by the parent. The method returns `Result<Option<Transaction>, Error>`. The transaction replaces the entire token and leaves the caret after a single space. An existing following space is consumed.

```rust
use gpdoc_plugin::core::{CommandContext, Error, Node, Transaction};

fn accept(ctx: CommandContext<'_>, choice: Node) -> Result<Option<Transaction>, Error> {
	Trigger::new('@').replace_with_atom(ctx, choice)
}
```
