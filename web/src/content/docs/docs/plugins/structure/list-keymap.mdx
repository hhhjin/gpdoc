`list_keymap()` handles list-specific key presses around bullet, ordered, and task items. At the start of the first item, Backspace can lift it out of the list.

## Try it

<PluginExample plugin="list-keymap" />

## Install

```sh
cargo add gpdoc-plugin-list-keymap
```

## Example

This example uses a bullet list. Add `gpdoc-plugin-bullet-list` and `gpdoc-plugin-list-item` to your [Quickstart project](/docs/quickstart/). Put the caret at the start of the first item and run the Backspace command.

```rust
use gpdoc::{DocPos, Editor, EditorConfig, Node, Selection};
use gpdoc_plugin_bullet_list::bullet_list;
use gpdoc_plugin_list_item::list_item;
use gpdoc_plugin_list_keymap::list_keymap;
use gpdoc_plugin_paragraph::paragraph;

let config = EditorConfig::builder()
    .plugin(paragraph())
    .plugin(list_item())
    .plugin(bullet_list())
    .plugin(list_keymap())
    .build()?;
let mut editor = Editor::from_document(&config, vec![Node::text("paragraph", "First item")])?;
editor.run(gpdoc_plugin_bullet_list::Toggle)?;
editor.select(Selection::caret(DocPos(3)))?;
editor.run(gpdoc_plugin_list_keymap::Backspace)?;

assert_eq!(editor.document().blocks()[0].kind, "paragraph");
```

## Settings

`gpdoc_plugin_list_keymap::list_keymap()` takes no options. Register it alongside the list types you use. [List kit](/docs/plugins/structure/list-kit/) includes both the keymap and the standard list types.

## Commands

Each command requires a collapsed text selection.

### `listBackspace`

At the beginning of the first item, lift the item one level. At the beginning of a later item, join its first paragraph to the preceding item’s final paragraph.

```rust
editor.run(gpdoc_plugin_list_keymap::Backspace)?;
```

### `listDelete`

At the end of an item, join its final paragraph to the following item’s first paragraph. Both sides of the boundary must be paragraphs.

```rust
editor.run(gpdoc_plugin_list_keymap::Delete)?;
```

### `listTab`

At the start of a text block immediately after a list, move that block into the last list item if the schema accepts it.

```rust
editor.run(gpdoc_plugin_list_keymap::Tab)?;
```

## Keyboard shortcuts

| Shortcut | Command |
| --- | --- |
| **Backspace** or **Mod + Backspace** | `listBackspace` |
| **Delete** or **Mod + Delete** | `listDelete` |
| **Tab** | `listTab` |
